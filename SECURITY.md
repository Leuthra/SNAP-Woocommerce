# Security Policy

## Supported versions

Only the latest release of this fork receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
through [GitHub Security Advisories](https://github.com/Leuthra/SNAP-Woocommerce/security/advisories/new).

Include the plugin version, WordPress and WooCommerce versions, and the steps
needed to reproduce the problem.
